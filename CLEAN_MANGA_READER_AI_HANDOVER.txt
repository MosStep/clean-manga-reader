[ 2. กฎเหล็กและข้อกำหนดที่ต้องทำตามเสมอ (CRITICAL RULES & CONSTRAINTS) ]

1. กฎการแนบลิงก์ (STRICT LINK RULE):
   - ทุกครั้งที่ตอบผู้ใช้ ตอนท้ายของข้อความให้แนบเฉพาะลิงก์นี้ลิงก์เดียวเท่านั้น:
     👉 https://clean-manga-reader.mosstep.workers.dev/
   - ห้ามแนบลิงก์ GitHub Repo หรือ GitHub Pages เว้นแต่ผู้ใช้จะเอ่ยปากขอโดยตรง

2. กฎการจัดลำดับตอน (CHAPTER SORTING RULE):
   - เมื่อเปิดดูรายชื่อตอนของมังงะทุกเรื่อง ทุกเว็บ ต้องจัดเรียงให้:
      ตอนที่ 1 อยู่ด้านล่างสุดเสมอ และตอนถัดไปไล่ขึ้นมา โดยตอนล่าสุดอยู่บนสุด
     (Numeric Descending: เช่น ตอนที่ 177, 176 ... ตอนที่ 2, ตอนที่ 1, บทนำ/Prologue)

3. กฎการเลือกเว็บเริ่มต้น & การจัดการเว็บติดเหรียญ (SOURCE PRIORITY & COIN HANDLING):
   - เมื่อกดเปิดดูตอนของมังงะเรื่องใดๆ ระบบต้องเลือกเว็บฟรีที่มีจำนวนตอนมากที่สุดขึ้นเป็นเว็บหลักอันดับ 1 เสมอ
   - หากมีเว็บไหนที่มีตอนนำ (เช่น NTRnaja มี 42 ตอน) แต่ตอนล่าสุดติดเหรียญ/ล็อคแต้ม:
     * ห้ามนำมาเป็นเว็บหลักเด็ดขาด ให้เว็บฟรีชนะและเป็นตัวหลักเสมอ
     * เอาเว็บติดเหรียญไว้ช่องสอง (Source Pill ลำดับถัดไป)
     * วงจำนวนตอนไว้ชัดเจน เช่น (42 ตอน) พร้อมแสดงสัญลักษณ์ `🔒 ติดเหรียญ` ชัดเจน
     * ตอนฟรีในเว็บนั้นสามารถกดอ่านผ่าน Vertical Reader ได้ปกติ ส่วนตอนที่ติดเหรียญจะมีปุ่มเปิดอ่านเว็บต้นทาง
     * เว็บ NTRnaja แม้จะมีคำว่า "NTR" ในชื่อ แต่เป็นการ์ตูนทั่วไป/มันฮวา ไม่ใช่เว็บ 18+ หรือโดจิน ห้ามจัดเข้าหมวดหมู่หรือแท็ก 18+ (โดจิน/18+) เด็ดขาด
     * การแกะตอนของ NTRnaja ต้องเจาะจงเฉพาะ .ss-chlist เพื่อไม่ให้ปุ่ม CTA "อ่านตอนล่าสุด" ด้านบนมาทำให้ตอนล่าสุดกลายเป็นฟรี และตัดข้อความวันที่ (เช่น อัปเดต 2026) ออกจากเลขตอนเสมอ

4. กฎประสิทธิภาพและการโหลดข้อมูล (PERFORMANCE & BACKGROUND LOADING):
   - ปลดล็อกหน้า UI ทันที 0s หากมีแคชในเครื่อง ผู้ใช้ต้องคลิกและเลื่อนดูเรื่องที่โหลดมาแล้วได้ทันที
   - ปล่อยหน้าเว็บให้แสดงผลภายใน 1 วินาที (Fast-Release)
   - เว็บไหนที่ตอบสนองช้า ให้ปล่อยโหลดเบื้องหลัง (Background Fetching) ด้วย Timeout 15 วินาที (timeoutMs = 15000)

5. ระบบประวัติการอ่าน & เรื่องโปรด & ซิงก์ข้ามเครื่อง (CLOUD SYNC & TOMBSTONES):
   - มีระบบ Private Sync Key 6 ตัวอักษร (เช่น ABC123) ซิงก์ข้อมูลขึ้น Cloudflare KV
   - เมื่อผู้ใช้ ลบ เรื่องโปรดหรือประวัติ จะมีการสร้าง Tombstone (deletedFavorites, deletedHistory)
     เพื่อป้องกันไม่ให้ข้อมูลเก่าที่อยู่บนคลาวด์ฟื้นคืนชีพกลับมาตอนซิงก์
   - จดจำชื่อเล่นที่ใช้คอมเมนต์ในห้องแชทผ่าน localStorage (CHAT_STORAGE_NICKNAME) และซิงก์ตาม Sync Key

6. การแก้ปัญหารูปภาพติด Hotlink Protection & ระบบกู้คืนภาพปกอัตโนมัติ (COVER AUTO-HEALING):
   - รูปภาพบนโดเมน server1.webtoon168.com (ของ Ped-Manga และ MangaStep)
     ต้องส่ง Referer เป็น https://ped-manga.com/ ใน Proxy Header เสมอ (ระบบใน app.js และ worker.js ทำไว้แล้ว)
   - รูปภาพของ Chibi-Manga (chibi-manga.com) ต้องส่ง Referer เป็น https://chibi-manga.com/ เสมอ
   - ระบบ Auto-Healing กู้คืนภาพปก: หากประวัติหรือรายการเรื่องใดไม่มีภาพปก (`cover: ""`)
     * เลเยอร์ 1: ตรวจสอบจับคู่ชื่อเรื่องกับ allMangaList หรือ altSources ทันที 0s
     * เลเยอร์ 2: หากยังไม่มี จะดึงจาก mangaUrl เบื้องหลังผ่าน Proxy มาสกัดภาพปก แล้วอัปเดตลง localStorage (STORAGE_HISTORY) ให้อัตโนมัติ
     * เปลี่ยนรูปภาพสำรอง (Placeholder) เป็น SVG รูป 📖 CleanManga ดีไซน์โมเดิร์น ไร้ข้อความ "Loading..." ค้าง

7. กฎการนำทางตอนก่อนหน้า/ตอนต่อไป (CHAPTER NAVIGATION & SAFE URLS):
   - ห้ามส่งค่า URL ที่เป็น placeholder เช่น `#/next/`, `#/prev/`, `#`, `javascript:...` เข้าสู่ Proxy โดยเด็ดขาด
   - มีฟังก์ชัน cleanChapterNavUrl เพื่อกรองและตรวจสอบความถูกต้องของ URL
   - ตรวจจับ script jQuery (พบบ่อยใน NTR-Manga และเว็บตระกูล MangaReader) ที่เซ็ต href ให้กับปุ่ม ch-next-btn / ch-prev-btn ในตอนที่ไม่มี ts_reader.run
   - มีระบบ Fallback อัจฉริยะ ดึงจาก cached_chapters ใน sessionStorage เพื่อคำนวณตอนก่อนหน้า/ถัดไป (index - 1 / index + 1) ได้อย่างแม่นยำ 100%

8. ปุ่มลูกศรลอยวาร์ปเลื่อนตอน (FLOATING SCROLL ARROWS):
   - ในหน้าต่างรายชื่อตอน (Modal) มีปุ่มลอยมุมขวาล่าง:
     * `⬇ ตอนที่ 1`: กดปุ๊บวาร์ปดิ่งลงไปล่างสุดเพื่อเจอตอนที่ 1 ทันที โดยไม่ต้องไถจอ (ถ้ามีหลายร้อยตอนจะกระโดดทันทีแบบ 0s ไม่ให้ค้าง)
     * `⬆ ตอนล่าสุด`: เมื่อเลื่อนลงมาแล้ว จะมีปุ่มกดวาร์ปกลับขึ้นมาดูตอนล่าสุดด้านบนสุดได้ตลอดเวลา

[ 4. โครงสร้างไฟล์และหน้าที่ (FILE ARCHITECTURE) ]
- index.html:
  หน้าหลัก แสดงคลังการ์ตูนทุกเว็บ, แถบตัวกรองภาษา [ไทย/อังกฤษ/ทั้งหมด], แท็บหมวดหมู่ (ทั้งหมด, มันฮวา, ประวัติ, เรื่องโปรด),
  กล่องค้นหาแบบ Realtime ข้ามค่าย, หน้าต่าง Modal รายชื่อตอน และแถบตั้งค่า Sync Key
- reader.html:
  หน้าอ่านการ์ตูนแนวตั้ง (Vertical Continuous Scroll), ปุ่มเปลี่ยนตอนก่อนหน้า/ถัดไป (ทั้งบนและล่าง),
  ปุ่มเปิดดูเว็บต้นทาง, ห้องแชทส่วนกลางที่ผูกแท็กการ์ตูนเรื่องนั้นให้อัตโนมัติ รองรับทั้งเว็บไทยและ MangaDex
- app.js:
  หัวใจหลักของฝั่ง Frontend:
  - fetchSingleSource, fetchMangaBatch, fetchMangaDexBatch: รวบรวมข้อมูลเรื่องล่าสุด
  - setupLanguageFilter, applyFilters: กรองภาษาโดยเน้นไทยเป็นหลัก
  - mergeAndDeduplicate: ผสานเรื่องซ้ำข้ามค่าย เลือกเว็บฟรีที่มีตอนมากที่สุดขึ้นนำ
  - parseChaptersFromHtml, fetchMangaDexChapters: แกะรายชื่อตอน และเรียก sortChaptersDescending (ตอน 1 อยู่ล่างสุดเสมอ)
  - cleanMangaChapterTitle: ทำความสะอาดชื่อตอน ตัดชื่อเรื่องซ้ำซ้อน และตัดวันที่ไทย/สากลทุกรูปแบบทิ้ง 100%
  - getReadingHistory: ดึงประวัติอ่านพร้อมระบบ Smart Deduplication ข้ามเว็บต้นทาง ยุบเรื่องซ้ำเหลือ 1 รายการ
  - recordReadingHistory: บันทึกประวัติอ่านลง localStorage ทันทีที่คลิกตอน และอัปเดตเลขตอนล่าสุดไม่ให้ค้าง
  - initSyncEngine, pushSyncData, pullAndMergeSyncData: ระบบซิงก์ข้ามเครื่องผ่าน Cloudflare KV
- config.js:
  ตั้งค่า SOURCES (ไทย 17 เว็บ) และ MANGADEX (อังกฤษ), PROXY_URL, CHAT_API_URL, SYNC_API_BASE
- style.css:
  สไตล์ Dark Modern ธีมเขียว-ฟ้า นีออน ปรับแต่ง Mobile First สบายตา พร้อม Badge ภาษา (🇹🇭 TH / 🇬🇧 EN / 🇯🇵 JA / 🇰🇷 KO) และปุ่ม Pill ไร้เครื่องหมายถูก
- worker/worker.js:
  Cloudflare Worker สำหรับทำ Proxy ปลดล็อก CORS, จัดการระบบแชทส่วนกลาง และเก็บข้อมูล KV Sync (Deduplicate ตามชื่อเรื่อง Normalized Title)

[ 5. อัปเดตล่าสุด v4.0 ]
- แก้ไขปัญหาการ์ตูน MangaDex (EN/JA/KO) ที่เคยกลายเป็น TH เมื่อบันทึกลงประวัติการอ่านหรือเรื่องโปรด (เก็บ lang ลง localStorage และคำนวณย้อนหลังให้อัตโนมัติ)
- หน้าแรกเมื่อเลือกหลายภาษาหรือเลือก [ทั้งหมด]: ระบบจะสลับการ์ตูนขึ้น (Interleave) ในอัตราส่วน 3 ไทย : 1 สากล ทำให้การ์ตูนภาษาอังกฤษ/สากลขึ้นมาแสดงคู่กับไทยบนหน้าแรกทันที ไม่ตกไปอยู่ท้ายสุด
- แก้ไขปัญหาภาษาญี่ปุ่น (ja) และเกาหลี (ko) จาก MangaDex ที่ก่อนหน้านี้ดึงแล้วเจอกลุ่มแปลเวียดนาม (vi) หรือตอนไม่ขึ้น:
  * เปลี่ยนพารามิเตอร์ค้นหาเป็น availableTranslatedLanguage[]=ja และ availableTranslatedLanguage[]=ko เพื่อดึงเฉพาะเรื่องที่มีตอนในภาษานั้นจริง 100%
  * ระบบ Fallback ของ MangaDex จะถอยไปหาภาษาอังกฤษ (en) เท่านั้น จะไม่ดึงภาษาเวียดนามหรือภาษาที่ไม่เกี่ยวข้องมาปะปน
  * ลิงก์ที่ไม่มีรูปหรือติดระบบสำนักพิมพ์ต้นทาง ปรับลิงก์เปิดเว็บต้นทางให้เป็น https://mangadex.org/chapter/... ป้องกันปัญหา mangadex:// Scheme
- การ์ตูนไทย 17 เว็บยังคงอยู่ครบถ้วน 100% และเป็นค่าเริ่มต้นเมื่อเข้าเว็บครั้งแรก
