[ 2. กฎเหล็กและข้อกำหนดที่ต้องทำตามเสมอ (CRITICAL RULES & CONSTRAINTS) ]

1. กฎการแนบลิงก์ (STRICT LINK RULE):
   - ทุกครั้งที่ตอบผู้ใช้ ตอนท้ายของข้อความให้แนบเฉพาะลิงก์นี้ลิงก์เดียวเท่านั้น:
     👉 https://clean-manga-reader.mosstep.workers.dev/
   - ห้ามแนบลิงก์ GitHub Repo หรือ GitHub Pages เว้นแต่ผู้ใช้จะเอ่ยปากขอโดยตรง

2. กฎการจัดลำดับตอน (CHAPTER SORTING RULE):
   - เมื่อเปิดดูรายชื่อตอนของมังงะทุกเรื่อง ทุกเว็บ ต้องจัดเรียงให้:
      ตอนที่ 1 อยู่ด้านล่างสุดเสมอ และตอนถัดไปไล่ขึ้นมา โดยตอนล่าสุดอยู่บนสุด
     (Numeric Descending: เช่น ตอนที่ 177, 176 ... ตอนที่ 2, ตอนที่ 1, บทนำ/Prologue)

3. กฎการเลือกเว็บเริ่มต้น (SOURCE PRIORITY RULE):
   - เมื่อกดเปิดดูตอนของมังงะเรื่องใดๆ ระบบต้องเลือกเว็บฟรีที่มี จำนวนตอนมากที่สุด ขึ้นเป็นเว็บแรกเสมอ
     (เช่น ถ้า Speed-Manga มี 177 ตอน และ Go-Manga มี 174 ตอน -> ต้องเลือก Speed-Manga เป็นตัวหลัก)
   - แถบสลับเว็บ (Modal Source Pills) ต้องเรียงจากเว็บฟรีที่มีตอนมากที่สุดอยู่ซ้ายสุด และแสดงจำนวนตอน

4. กฎประสิทธิภาพและการโหลดข้อมูล (PERFORMANCE & BACKGROUND LOADING):
   - ปลดล็อกหน้า UI ทันที 0s หากมีแคชในเครื่อง ผู้ใช้ต้องคลิกและเลื่อนดูเรื่องที่โหลดมาแล้วได้ทันที
   - ปล่อยหน้าเว็บให้แสดงผลภายใน 1 วินาที (Fast-Release)
   - เว็บไหนที่ตอบสนองช้า ให้ปล่อยโหลดเบื้องหลัง (Background Fetching) ด้วย Timeout 15 วินาที (timeoutMs = 15000)

5. ระบบประวัติการอ่าน & เรื่องโปรด & ซิงก์ข้ามเครื่อง (CLOUD SYNC & TOMBSTONES):
   - มีระบบ Private Sync Key 6 ตัวอักษร (เช่น ABC123) ซิงก์ข้อมูลขึ้น Cloudflare KV
   - เมื่อผู้ใช้ ลบ เรื่องโปรดหรือประวัติ จะมีการสร้าง Tombstone (deletedFavorites, deletedHistory)
     เพื่อป้องกันไม่ให้ข้อมูลเก่าที่อยู่บนคลาวด์ฟื้นคืนชีพกลับมาตอนซิงก์
   - จดจำชื่อเล่นที่ใช้คอมเมนต์ในห้องแชทผ่าน localStorage (CHAT_STORAGE_NICKNAME) และซิงก์ตาม Sync Key

[ 4. โครงสร้างไฟล์และหน้าที่ (FILE ARCHITECTURE) ]
- index.html:
  หน้าหลัก แสดงคลังการ์ตูนทุกเว็บ, แท็บหมวดหมู่ (ทั้งหมด, มันฮวา, ประวัติ, เรื่องโปรด),
  กล่องค้นหาแบบ Realtime ข้ามค่าย, หน้าต่าง Modal รายชื่อตอน และแถบตั้งค่า Sync Key
- reader.html:
  หน้าอ่านการ์ตูนแนวตั้ง (Vertical Continuous Scroll), ปุ่มเปลี่ยนตอนก่อนหน้า/ถัดไป (ทั้งบนและล่าง),
  ปุ่มเปิดดูเว็บต้นทาง, ห้องแชทส่วนกลางที่ผูกแท็กการ์ตูนเรื่องนั้นให้อัตโนมัติ
- app.js:
  หัวใจหลักของฝั่ง Frontend:
  - fetchSingleSource, fetchMangaBatch: รวบรวมข้อมูลเรื่องล่าสุด
  - mergeAndDeduplicate: ผสานเรื่องซ้ำข้ามค่าย เลือกเว็บฟรีที่มีตอนมากที่สุดขึ้นนำ
  - parseChaptersFromHtml: แกะรายชื่อตอน และเรียก sortChaptersDescending (ตอน 1 อยู่ล่างสุดเสมอ)
  - recordReadingHistory: บันทึกประวัติอ่านลง localStorage อัตโนมัติ
  - initSyncEngine, pushSyncData, pullAndMergeSyncData: ระบบซิงก์ข้ามเครื่องผ่าน Cloudflare KV
- config.js:
  ตั้งค่า SOURCES, PROXY_URL, CHAT_API_URL, SYNC_API_BASE
- style.css:
  สไตล์ Dark Modern ธีมเขียว-ฟ้า นีออน ปรับแต่ง Mobile First สบายตา
- worker/worker.js:
  Cloudflare Worker สำหรับทำ Proxy ปลดล็อก CORS, จัดการระบบแชทส่วนกลาง และเก็บข้อมูล KV Sync
